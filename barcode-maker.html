Which Barcode Should You Choose?

Different barcode types hold different content and aren't all readable by the same scanners. Here's a quick guide to each format.

Code 39

The most widely supported barcode. Stores letters, numbers and a handful of symbols, and can be read by almost any scanner.

Code 128

Stores any alphanumeric character more efficiently than Code 39, making it a strong default for asset and inventory tracking.

Interleave 2 of 5

Numbers only. Commonly used for industrial and master carton labeling.

Codabar

An older numeric-based format still commonly used in libraries and blood banks.

Code 93

Similar to Code 39 but more compact, letting you store more characters in less space.

MSI Plessey

A numeric-only format commonly used in warehousing and shelf/inventory labeling.

UPC-A

The standard 12-digit retail barcode used at checkout across the US and Canada.

UPC-E

A compressed 6-digit version of UPC-A, used to fit small packages like paperbacks.

EAN-13

The international counterpart to UPC-A, widely used for retail products outside North America.

EAN-8

A shortened EAN format for smaller retail packaging that can't fit a full EAN-13.

U.S. Postal Code

Also called POSTNET — used by the US Postal Service for mail routing and delivery.

QR Code

A two-dimensional code that can hold thousands of characters, including URLs and contact details — scannable by any modern smartphone.

Frequently Asked Questions

What is a barcode generator?

A barcode generator converts data — like a product number, SKU, or asset ID — into a scannable image that can be printed or scanned. This tool creates common 1D and 2D formats like Code 128, Code 39, UPC-A, EAN-13, and QR Codes directly in your browser, with no account or payment required.

How do I print a barcode after I create it?

Download the PNG image and print it from any standard application. For occasional use, a regular inkjet or laser printer with label sheets works fine. For higher-volume or more durable labels, a thermal barcode printer produces sharper results that hold up better in warehouse, shipping and asset-tracking environments.

What's the difference between UPC, EAN, Code 128, Code 39 and QR codes?

UPC and EAN are retail point-of-sale codes — UPC is standard in the US and Canada, EAN internationally. Code 128 and Code 39 are used for inventory, asset tracking and warehouse labeling; Code 128 stores data more efficiently. QR Codes are two-dimensional and can store far more information, including URLs and contact details, and can be scanned with most smartphone cameras.

What's the difference between 1D and 2D barcodes?

1D (linear) barcodes like UPC, EAN, Code 128 and Code 39 store data in a single row of bars and scan very quickly, which is why they're common in retail and shipping. 2D barcodes like QR Codes store data in a grid and can hold much more information, and can be scanned with a smartphone camera as well as dedicated scanners.

Can I generate barcodes in bulk?

This tool is built for creating individual barcodes one at a time. For bulk generation involving hundreds or thousands of unique codes, Wasp Inventory and Wasp Asset both include built-in barcode creation and printing as part of the full tracking platform — most businesses managing more than 50-100 items find this a better fit than generating labels one by one.

After I create a barcode, how do I actually track inventory or assets with it?

A barcode by itself is just a label — to actually track inventory or assets, you need scanners and software that record each scan against a database. Wasp Inventory and Wasp Asset both pair with barcode scanners to track check-in/check-out activity, stock levels, audits and maintenance history automatically.
